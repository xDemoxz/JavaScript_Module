# Sistema Interactivo en JavaScript

Este proyecto es un ejercicio básico en JavaScript donde el programa interactúa con el usuario solicitando su nombre y edad.

Según la edad ingresada, el sistema muestra un mensaje diferente y además valida que la edad sea escrita correctamente en números.

## Lo que se trabajó en este ejercicio

- Uso de variables con `let`
- Entrada de datos con `prompt()`
- Mensajes usando `alert()`
- Manejo de errores con `console.error()`
- Condicionales `if` y `else`
- Conversión de datos con `Number()`
- Buenas prácticas en nombres de variables

## Cómo funciona

1. El programa pide el nombre del usuario.
2. Luego solicita la edad.
3. Verifica si la edad ingresada es válida.
4. Dependiendo de la edad:
   - Si es menor de 18, muestra un mensaje para menores de edad.
   - Si es mayor o igual a 18, muestra un mensaje para mayores de edad.
5. Si la edad no es un número, aparece un error en consola.
